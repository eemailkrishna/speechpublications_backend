================================================================================
                            QUICK START GUIDE
================================================================================

STEP 1: Get Razorpay Keys (2 minutes)
  → https://dashboard.razorpay.com/signin
  → Settings → API Keys
  → Copy Key ID & Key Secret

STEP 2: Add to .env (1 minute)
  RAZORPAY_KEY_ID=your_key_id
  RAZORPAY_KEY_SECRET=your_key_secret

STEP 3: Run Migrations (1 minute)
  php artisan migrate
  php artisan config:clear

STEP 4: Test Checkout (1 minute)
  → Login to app
  → Add items to cart
  → Go to /checkout
  → Test COD or Razorpay

TOTAL TIME: ~5 minutes ⚡
