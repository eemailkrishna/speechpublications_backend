🔄 HOW IT WORKS:

  ┌─────────────┐
  │ User clicks │
  │  [+] or [−] │
  └──────┬──────┘
         │
         ▼
  ┌─────────────────────────┐
  │ Quantity input updated  │
  │ visually                │
  └──────┬──────────────────┘
         │
         ▼
  ┌──────────────────────────────┐
  │ AJAX request sent to server  │
  │ (POST /cart/update/{id})     │
  └──────┬───────────────────────┘
         │
         ▼
  ┌──────────────────────────────┐
  │ Server processes request     │
  │ Updates database/session     │
  │ Returns JSON: {success:true} │
  └──────┬───────────────────────┘
         │
         ▼
  ┌──────────────────────────────┐
  │ JavaScript receives response │
  │ Updates prices on page       │
  │ Shows notification           │
  └──────┬───────────────────────┘
         │
         ▼
  ┌──────────────────────────────┐
  │ ✓ All done in 200ms!         │
  │ ✓ No page refresh!           │
  │ ✓ Smooth user experience!    │
  └──────────────────────────────┘
